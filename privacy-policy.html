Savage DRX

Server Activity

Privacy Policy · Last updated: 20 October 2026

Savage DRX Server Activity is a browser extension that shows the busiest Savage DRX server's player count on your toolbar, with server, map and player details.

Data we collect

None. The extension does not collect, store, sell or share any personal information. It has no accounts, analytics, advertising or tracking.

What the extension does on your device

  • It fetches public server data and images from api.savagedrx.com and savagedrx.com.
  • It saves the latest server data in your browser's local extension storage so the popup opens quickly. This stays on your device and is never sent anywhere.
  • It uses a background timer to refresh that data periodically.

Third parties

Requests go only to the Savage DRX API and website listed above. Those sites may log standard connection information (such as your IP address) as any website does; see their own policies. Links in the popup (for example Socials and Servers) open external pages in a new tab.

Remote code

The extension does not load or run remote code.
